# श्रीमद्भगवद्गीता — द्वादशोऽध्यायः (भक्तियोगः)
## Bhagavad Gita Chapter 12: Bhakti Yoga Web Application

An interactive, responsive web application presenting all 20 Sanskrit shlokas of Chapter 12 (Bhakti Yoga) with synchronized recitation audio and real-time colored text highlighting.

### 🌟 Features
- **All 20 Sanskrit Shlokas**: Crisp Devanagari typography with speaker tags.
- **Synchronized Recitation Highlighting**: Chanted words light up in radiant gold with a smooth colored overlay in exact lockstep with the voice.
- **Zero-Latency Audio**: Leading pauses/silences trimmed for instantaneous playback on click.
- **Multiple Audio Sources**:
  - 🎵 Traditional Sanskrit Chanting
  - 🎙️ Clear Vedic Recitation
  - 📖 Complete Shloka & Narration
- **Full Interactive Controls**:
  - Word Click-to-Seek: Click any Sanskrit word to jump audio to that exact syllable.
  - Interactive Scrubber: Scrub and drag across the progress bar (mouse & touch support).
  - Variable Speed: 0.75x, 1.0x, 1.25x, 1.5x.
  - Repeat & Loop Mode.
  - Optional Auto-Advance: Automatically moves to the next shloka when the current one finishes.
  - Quick Navigation: 1–20 Jump Pills and real-time Sanskrit search.
- **Mobile Optimized**: Responsive UI, touch-friendly tap targets, and horizontal scroll navigation.
- **Theming**:
  - 🌙 Golden Amber
  - 🌲 Vedic Emerald
  - 🌊 Deep Sapphire
  - 📜 Serene Parchment
